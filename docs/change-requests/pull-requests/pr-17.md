# PR #17 — Robo: Reference Sheet download, Production Rate chart fixes, and S.No. 1..N correction
State: MERGED  Merged: 2026-09-09T05:40:55Z


Three Robo module changes:

### 1. Reference Sheet download (Downloads page)
A new "Reference Sheet" section: enter a Design Name and download a one-page Excel
summary of that design's LATEST production run — Production Date, Batch No., Design,
Thickness, Total Slabs, Total Production Time, Total Delays, Avg Slabs/hour, the Robo
program names actually used, and any Robot (G-category) delays that occurred.
Matches by design name only, ignoring thickness ("Costa 2 cm" and "Costa 3 cm" are
one design; "Bellagio Green" and "Bellagio Grey" are not). Shows "No previous
production record found" when a design has never run. Reuses the existing Reports
calculations. No schema change.

### 2. Production Rate per Hour — date & label fixes
- A slab held open for hours (a long delay) no longer fabricates a phantom extra
  day: the timeline is rebuilt from In→In continuity, not off a late Out time.
  Single-day runs stay on one day; genuine two-day runs no longer sprout a third.
- An overnight slab whose Out time is before its In time is correctly counted on
  the next day.
- The first X-axis time label is no longer clipped ("18:00–19:00", not ":00–19:00").

### 3. S.No. — computed 1..N per batch, not the mistyped stored value
S.No. is now derived from the physical slab-number order (the authoritative
production sequence) instead of the operator-typed serialNumber, which was mistyped
on old runs (a batch numbering 1…36 then restarting at 24, appearing to end short of
its real slab count). Every batch now reads a clean 1…N in the download sheets, on
the slab detail page, and in a new S.No. column on Slab Records. Fixes old and new
records uniformly — no data migration, no schema change.
