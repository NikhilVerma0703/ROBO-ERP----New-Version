# PR #13 — NEW : Robo + Chromia: round-2 updates (14 changes)
State: MERGED  Merged: 2026-08-28T05:27:32Z

Second batch of Robo and Chromia improvements on top of the earlier
`feat/robo-chromia-changes` work. App code and tests only — **no Prisma schema,
SQL, or migration changes**, so nothing to run against the database. `tsc`,
`next build`, `npm test` and `npm run test:chromia` are all green.

## Robo (8)
- **Entry — next numbers:** the next S.No. and Slab No. now count from the last *saved* row of the register (last + 1), not the max in the table, so it no longer offers a stale/"random" S.No. or a blank slab number.
- **Entry — delay picker:** a delay code chosen but not added no longer stays selected on the next slab; the picker resets when a slab is saved.
- **Entry — tablet layout:** the form is laid out for the iPad it's typed on (breakpoints moved off iPad-portrait width); desktop is unchanged.
- **Masters — Operators removed:** the Operators section is gone from Masters (model and seed left intact; nothing else affected).
- **Downloads:** Production Records and Delay List sheets reshaped and grouped date-wise, with per-date and overall totals.
- **Slab Records:** results table reordered, Batch No. column added, the three actions collapsed under one "Action" header.
- **Entry — Recent Slabs:** the "#" column header renamed to "S.No.".
- **Entry — new batch:** starting a new batch opens the setup form empty instead of carrying the previous run's values.

## Chromia (6)
- **Slab Records:** filtered results all show on one page, and applied filters persist through completing QC (no more re-applying the month filter per slab).
- **Filters:** Production Date / Batch / Slab filters added to the Stockyard and Recalibration pages.
- **Stockyard:** a Recalibration action for stocked slabs, beside Dispatch, wired into the existing recalibration workflow.
- **Timezone:** every date-time now reads and writes in the plant's timezone (Asia/Kolkata) instead of the server's UTC — QC time, Entered, Created and the export sheets all show the correct local time. (Historical rows entered under the old convention read shifted until re-entered; new records are correct.)
- **Dashboard / Summary:** "…Received" labels renamed to "Produced", and the "Latest QC Outcomes" section removed from the Dashboard.
- **Downloads:** Complete Production and By Outcome sheets gain S.No., show In-time as time-only, drop Out-time, and add Grade / Slab Remarks from the slab record.

## Notes
- Slab No. and Batch No. already accept alphanumerics (e.g. `59183-A`) — verified, no change needed.
- Does not touch Robo, Fabrication, Cutting, Consumables, Sales or any unrelated module.
- For review only — not intended to be merged or deployed by this PR.
